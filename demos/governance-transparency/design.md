# Governance demo design

Review prototype for the accepted CrossOmics Tool governance proposal. Retain the Community identity: white #ffffff, navy #182e4a, blue #0b57d0, pale blue #eff5fc, quiet slate #4f6074, verified green #187252. Use the system CJK sans stack, 16px body, 14px labels and a 36px page title. No external fonts or imagery; the public event chain and readable before/after changes carry the visual identity.

Layout: slim Community header, Tool context with two actions, four tabs, a wide chronological ledger beside an event detail inspector. One distinct pale blue checkpoint strip binds the view. Team and proposals reuse aligned rows; verification uses explicit pass/fail steps rather than decorative status metrics. At mobile widths the inspector follows the ledger and controls wrap. Every mutation is clearly simulated; keys and witnesses are local browser actors.

Interactions: select event, inspect the readable delta and raw proof, verify or tamper with a copy, download evidence, simulate administrator grants, maintainer recommendation, team majority and candidate acceptance. Real SHA-256, ECDSA P-256 and Merkle inclusion proofs support the demo; no production authority is claimed.
